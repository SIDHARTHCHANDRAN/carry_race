# Carry Race: Ripple vs Carry Look-Ahead Adder

COA (CSE 2257) Module 3 project: an interactive simulation that races a ripple-carry adder against a carry look-ahead adder, one gate delay at a time.

**Live demo:** https://YOUR-USERNAME.github.io/carry-race

## Features
- 4-bit and 8-bit adders, any A, B and carry-in
- Start / pause / step through gate delays
- Bits show `?` until their signal is valid, then light up
- Worst-case button (1111 + 0001) and random inputs
- Speed-up banner and scaling chart (4 to 32 bits)

## Run locally
Open `index.html` in a browser. No build step.

## Files
- `index.html`: the simulation
